为什么开博客

写作是最好的思考方式。把学到的、踩过的坑、想明白的事写下来:

  • 输出倒逼输入,写不清楚的地方往往就是没想明白的地方
  • 记录成长的轨迹,回头能看见自己的变化
  • 万一能帮到屏幕前的你,那就更好了

这个博客能做什么

本站使用自研的 Aurora 主题,支持:

  1. 暗色/亮色一键切换 —— 右上角按钮,偏好会被记住
  2. 站内全文搜索 —— 按 Ctrl + K 试试
  3. 评论区 —— 基于 Giscus,用 GitHub 账号即可留言
  4. 阅读进度条 + 回到顶部 —— 长文友好

目录与导航

文章右侧(桌面端)有随滚动高亮的目录;顶栏可以直达归档、标签、分类与关于页。
